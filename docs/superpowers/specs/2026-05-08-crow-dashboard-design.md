# Crow Health Dashboard Design Spec

**Date:** 2026-05-08
**Status:** Draft
**Topic:** Reworking Crow TUI from an FTP Browser into a Workspace Health Dashboard.

## 1. Overview
Crow is shifting from a standard FTP client to a "Virtual Workspace" tool. The previous dual-panel TUI (`crow browse`) is being replaced by `crow dashboard`, a specialized monitoring and maintenance center for the virtual workspace.

## 2. Goals
- Provide a real-time view of workspace health.
- Monitor Watcher and Sync activity.
- Automate workspace repair ("Dashboard Doctor").
- Enhance accessibility via OS-specific shortcuts in the project root.

## 3. Dashboard Layout (Textual TUI)
The dashboard will utilize a 3-section layout:

### 3.1. Header & Stats Bar
- **Header**: Displays "CROW DASHBOARD", active FTP host, and connection status.
- **Stats Bar**:
    - **Integrity**: Health score or Status (Healthy/Repair Needed).
    - **Sync Progress**: Progress bar or counts (`Skeleton vs Synced`).
    - **Quota/Storage**: (If supported) Remote storage usage.

### 3.2. Body (Split View)
- **Left Panel (Workspace Doctor)**:
    - Lists critical workspace components: `.crow-manifest.json`, `workspace/` folder, `CROW.md`.
    - Shows status for each (Found/Missing).
    - **Action**: `[F] Fix Workspace` - Recreates missing skeleton files/folders based on manifest.
- **Right Panel (Watcher Feed)**:
    - Live scrolling log of the background Watcher's activities.
    - Shows uploads, downloads, and conflict detections.

### 3.3. Bottom Panel (Conflict Manager)
- Lists files in a "Blocked" or "Dirty" state.
- Allows user to manually resolve or ignore conflicts.

## 4. Features & Logic

### 4.1. The Dashboard Doctor
- Periodically checks for the existence of the workspace root and manifest.
- **Auto-Fix (Option A)**: If the dashboard is opened and the `workspace/` folder is missing, it will automatically recreate the folder and all ghost files (0kb) listed in the manifest.

### 4.2. OS Shortcut Generation
During `crow workspace init`, Crow will generate a shortcut in the project root:
- **Linux/macOS**: `crow-dashboard.sh` (chmod +x).
- **Windows**: `Crow Dashboard.bat`.
These shortcuts execute `crow dashboard` in the current environment.

### 4.3. Command Rework
- `crow browse` is **DEPRECATED** and removed.
- `crow dashboard` becomes the primary TUI command.

## 5. Technical Implementation
- **UI Framework**: Textual (Python).
- **State Management**: Dashboard will poll the `Manifest` and a local `activity.log` (generated by the Watcher).
- **Repairs**: Logic moved from `crow/commands.py` to a more central `crow/workspace.py` helper if needed.
